# Hi, I'm Julie 👋

Marketing leader with 15+ years in commercial real estate and structured finance. These days I build the tools instead of only briefing them.

Most recently I led marketing for a C-PACE lending platform that grew from $103M to $1B+ in financing volume.

## What's here

**[cpace-finder](https://github.com/juliechasen-cyber/cpace-finder)** — a free 50-state C-PACE program finder. Every rule is read from the program administrator's own guidelines or the statute, with the source and the date checked. If something isn't verified, it says so instead of guessing.

**[julies-b2b-lead-generator](https://github.com/juliechasen-cyber/julies-b2b-lead-generator)** — a Claude Code pipeline that finds companies matching an ICP and shows the evidence they may need what you sell. Ten stages, no fabricated contacts, and nothing is ever sent without a human.

**[cre-lead-console](https://github.com/juliechasen-cyber/cre-lead-console)** — a single-file console for working a CRE lead list: score, qualify, track outreach, export a buyer-ready CSV. [Live demo](https://juliechasen-cyber.github.io/cre-lead-console/) on synthetic data.

**[cre-press-release-generator](https://github.com/juliechasen-cyber/cre-press-release-generator)** — a free tool for CRE brokers. Fill out a short form, get a wire-format press release draft in about a minute. Next.js + Claude, live at [cre-press-release-generator.vercel.app](https://cre-press-release-generator.vercel.app).

**[starter-session-audit](https://github.com/juliechasen-cyber/starter-session-audit)** — a Claude Code skill that catches the corrections, preferences, and decisions a working session produces, then proposes where to save them. MIT licensed.

**[juliechasen.com](https://github.com/juliechasen-cyber/juliechasen.com)** — source for my portfolio site. Hand-built HTML and CSS.
